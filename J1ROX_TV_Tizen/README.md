# J1ROX TV — Samsung Tizen

Отдельный Web-клиент Samsung TV 4.0+, использующий существующий ATODO backend.
Android и iOS не требуются и не изменяются. Runtime не использует npm-библиотеки.

Есть главная, каталоги фильмов/сериалов с пагинацией, поиск с русской/латинской
экранной клавиатурой, карточки и описания, источники, озвучки, сезоны, серии,
избранное и локальный прогресс. Нативный AVPlay получает свежую ссылку при каждом
старте; браузерный preview использует HTML video с явно показанной ошибкой,
если браузер не поддерживает HLS. Тестовые данные находятся только в tests/.

Интерфейс использует сцену 1920×1080 с масштабированием, включая 4K.
Фокус пространственный, пульт работает без мыши; в плеере ↑/↓ выбирают действия,
←/→ перематывают, Return закрывает панель/плеер. Прогресс хранит номера серий,
а не истекающие CDN-ссылки. При возвращении из фона поток запрашивается заново.

## Разработка

```powershell
Set-Location -LiteralPath 'C:\J1r0xTV\J1ROX_TV_Tizen'
npm.cmd ci
npm.cmd run check
npm.cmd test
npm.cmd run test:browser
node tests/browser.cjs --live
python tools/network-audit.py
python tools/package-unsigned.py
```

Браузерные тесты по умолчанию используют Chrome из Program Files.
Другой Chromium можно указать переменной `JTV_BROWSER` (путь к exe).
Для ручного preview: `python -m http.server 8080 --bind 127.0.0.1`, затем
откройте `http://127.0.0.1:8080`. Сообщение 404 для `$WEBAPIS` в обычном браузере
ожидаемо: библиотека предоставляется телевизором. Это не эмуляция AVPlay.
