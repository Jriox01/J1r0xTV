# Смотреть вместе

В карточке фильма/сериала и в нижней панели плеера есть кнопка «Смотреть вместе».
Системный `GroupActivitySharingController` предлагает участников/FaceTime и обрабатывает
отмену приглашения. Для сериала используется выбранная серия (по умолчанию первая доступная).
Во время сессии кнопка показывает число участников и меню выхода/завершения для всех.
Настройки источника, озвучки, сезона и серии доступны в плеере через «Настройки».

## Устройство

- `SharePlay/J1ROXWatchTogetherActivity.swift`: идентификаторы контента и metadata активности.
- `SharePlay/WatchTogetherMessage.swift`: Codable-события, полное логическое состояние,
  версии Lamport и детерминированный выбор владельца автоматического перехода.
- `SharePlay/WatchTogetherManager.swift`: постоянный слушатель сессий, messenger,
  участники, разрешение входящего контента, подключение AVPlayer, отмена задач и cleanup.
- `SharePlay/WatchTogetherResolver.swift`: существующий ProviderResolver получает поток
  на каждом устройстве отдельно. URL, cookies и HTTP-заголовки не передаются участникам.
- `SharePlay/WatchTogetherButton.swift`: общий интерфейс приглашения и выхода.

AppViewModel запускает слушатель при создании приложения, поэтому приглашение работает
и без открытого плеера. Входящий контент открывается через существующий PlaybackSelection /
PlayerScreen; уже открытый PlayerScreen получает новый selection без пересоздания AVPlayer.

Play/pause/seek и позицию синхронизирует `AVPlayerPlaybackCoordinator`. Delegate возвращает
стабильный ID фильма/сезона/серии, независимый от URL, источника и озвучки.
При первой загрузке координатор подключается после локального восстановления позиции;
после подключения внутренние замены item выполняются в suspension и завершаются `end()`
без предложения локального времени группе. Таймера сетевой синхронизации нет.

Источник, озвучка, сезон и серия передаются через GroupSessionMessenger после успешного
локального выбора. Входящие события и автоматический fallback не публикуются обратно.
Каждое событие содержит полное состояние: более новые версии заменяют старые, а равные
версии/повторные сообщения игнорируются. При одновременных событиях с одинаковым счётчиком
победителя определяет ID автора. Новые участники запрашивают snapshot; ответы с устаревшими
версиями не откатывают состояние. Позицию позднего участника определяет координатор.

Countdown запускает участник с минимальным UUID среди текущих участников. Право перехода
проверяется повторно после загрузки потока. После ухода владельца выбирается следующий.
Передаётся конкретный номер следующей серии, а не команда «прибавить 1». Отмена countdown
остаётся доступной на устройстве владельца; обычный одиночный countdown сохранён.

## Ошибки и жизненный цикл

Сначала проверяется запрошенный provider/source и озвучка по имени. Если они недоступны,
используется существующий перебор источников, текущая доступная озвучка, затем доступная
озвучка по умолчанию. Сезон и эпизод должны совпадать точно; другая серия не подставляется.
При смене источника/озвучки сохраняется локальный snapshot, после готовности AVPlayer
возвращается к времени группы. Разные монтажные версии могут иметь разные таймлайны:
сопоставление сцен между такими версиями не выполняется.

Если запрошенная серия полностью недоступна, участник выходит из SharePlay, получает
понятное сообщение и сохраняет текущий плеер. Ошибки messenger и исчерпание восстановления
потока также освобождают сессию. Быстрые изменения отменяют прежние загрузки; generation
проверяется перед применением результата. При закрытии плеера выход из группы выполняется
до pause/stop. При invalidation отменяются задачи и subscriptions; AVPlayer не уничтожается.
Background audio уже включён в Info.plist: сворачивание не закрывает сессию, сетевые stall
и audio interruption обрабатывает нативный координатор.

## Xcode и проверка

Minimum deployment target остаётся iOS 16.0. Добавлены Group Activities capability и
`Resources/J1ROXTV.entitlements` (`com.apple.developer.group-session`) для Debug и Release.
Team, Bundle ID и способ подписи сохранены. Provisioning profile для установки должен
содержать этот entitlement; при необходимости его нужно обновить в Apple Developer/CI.

`Tests/WatchTogetherTests.swift` включён в существующий `Tests/run-provider-tests.sh`
для Debug/Release: wire format, идентификаторы, дубли/устаревшие сообщения, одновременные
изменения, snapshot позднего участника, выбор владельца для 3 участников и fallback.
На Windows выполнены статический разбор изменённых Swift-файлов, проверка plist/project
и git diff. Xcode/iOS SDK и Swift compiler здесь отсутствуют; сборка и выполнение Swift-тестов
на Windows не подтверждены. Существующий ios-check CI запускает сборки после push.

Проверка на двух и трёх физических устройствах с разными Apple ID:

1. Пригласить из карточки, затем из уже играющего плеера; проверить отмену приглашения.
2. На каждом устройстве проверить play/pause/seek; подключить третье устройство позже.
3. Сменить источник и озвучку, сезон и серию; быстро выбрать несколько серий подряд.
4. Дождаться countdown: 5 → 6 без 7; отдельно отменить countdown и удалить владельца из группы.
5. Проверить недоступный источник/озвучку/серию, потерю сети и возвращение из background.
6. Выйти из сессии, завершить её для всех, закончить FaceTime и закрыть плеер свайпом.
7. В одиночном режиме проверить прогресс/продолжение, источники, озвучку, загрузки,
   качество и нативные AVKit controls. Проверить поведение при заблокированном экране.

[приглашение участников](https://developer.apple.com/documentation/groupactivities/groupactivitysharingcontroller-ybcy),
