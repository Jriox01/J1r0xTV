# Изменения экрана сериала

Используются существующие DetailsViewModel, StreamingService, PlaybackSession,
PlayerSession, LibraryStore и DownloadManager. Данные приложения остаются реальными;
SeriesFixture используется исключительно в регрессионных тестах.

## Реализация

- Общие SwiftUI Menu для источника, озвучки и сезона на странице контента и в плеере.
- Компактные строки серий, выделение выбора, индивидуальная загрузка и её статус.
- Первая доступная озвучка при отсутствии выбора; локальное предпочтение по типу и ID
  контента; при исчезновении предпочтения используется первая доступная озвучка.
- Сезоны/серии сортируются по номеру. Выбор сезона заменяет список серий.
- Явное переключение потока не подменяет источник резервным. Существующее
  автоматическое восстановление после ошибки плеера сохранено.
- Позиция и состояние воспроизведения снимаются перед сменой потока. Seek выполняется
  после readyToPlay, ограничивается длительностью нового потока. Прогресс сохраняется
  прежним LibraryStore/Core Data; отдельного хранилища прогресса нет.
- AVPlayerItemDidPlayToEndTime запускает отменяемый отсчёт 5–1. Есть немедленный запуск,
  переход между сезонами, защита от повторного окончания и отмена при закрытии/выборе.
- Устаревшие ответы выбора и восстановления плеера не заменяют свежий выбор.
- Качества берутся из HLS-манифеста либо явных прямых вариантов API. Единственный
  вариант скачивается сразу, несколько открывают выбор. DownloadManager сохраняет
  контент, сезон, серию, источник и озвучку и предотвращает повторную загрузку.

## Фактическая проверка в Windows

- `git diff --check`: успешно (сообщения Git о нормализации CRLF не являются Swift warnings).
- Синтаксический разбор изменённых Swift-файлов Tree-sitter: новых ошибок относительно
  HEAD не найдено. Парсер не понимает некоторые уже существовавшие конструкции Swift;
  это не проверка типов и не замена Swift compiler.
- Попытка `xcodebuild -project J1ROX_TV_iOS/J1ROXTV.xcodeproj -scheme J1ROXTV
  -sdk iphonesimulator build`: не выполнена, команда отсутствует в Windows.
- Компиляция Debug/Release, Swift warnings, AVPlayer, реальное API и загрузки на
  устройстве/симуляторе **не проверены**. Успешная сборка не заявляется.

## Регрессии для macOS

В существующий `Tests/run-provider-tests.sh` добавлены SeriesTests и зависимости.
Новые тесты покрывают первую/сохранённую/исчезнувшую озвучку, сохранение серии,
замену списка сезона, следующую серию/сезон, конец сериала, пустой ответ и гонку
ответов источников. Они подготовлены, но в этой среде не запускались.

На Mac выполнить:

```sh
cd J1ROX_TV_iOS
bash Tests/run-provider-tests.sh
xcodebuild -project J1ROXTV.xcodeproj -scheme J1ROXTV -configuration Debug -sdk iphonesimulator CODE_SIGNING_ALLOWED=NO build
xcodebuild -project J1ROXTV.xcodeproj -scheme J1ROXTV -configuration Release -sdk iphonesimulator CODE_SIGNING_ALLOWED=NO build
```

После сборки остаются обязательными все интерактивные сценарии пользователя:
открытие/возвращение в сериал; выбор каждого элемента; ручной запуск; окончание;
5-секундный отсчёт, отмена и немедленный запуск; границы сезонов и сериала;
переключение на ненулевой позиции, в паузе и быстрыми повторными нажатиями;
закрытие во время отсчёта/запроса; скачивание каждой серии с выбором качества,
статусами, ошибкой и повторным нажатием на скачанное; пустые/единичные списки.

## Ограничения данных

Если API/манифест не сообщает варианты качества, показывается единственный
реальный вариант («Оригинал», если качество неизвестно). 1080p не добавляется
искусственно. Прямые ссылки должны поддерживаться текущим DownloadManager.
Для HLS сохранён существующий системный механизм выбора по минимальному битрейту
на master URL, чтобы не потерять внешнюю аудиодорожку: AVFoundation может выбрать
вариант выше указанного, точное разрешение загруженного пакета здесь не подтверждено.
Офлайн-плеер не запускает автоматически следующую сетевую серию.
