# TMDB / Codemagic

В проекте используется официальный TMDB API для каталога, поиска и карточек. Поддерживаются API Read Access Token и API Key. В Codemagic настройте секретную переменную TMDB_READ_ACCESS_TOKEN или TMDB_API_KEY в окружении workflow. Первый шаг каждого workflow передаёт её в Info.plist без вывода значения в лог. При наличии обоих используется токен. Значения ключей в ZIP отсутствуют. В собранном приложении ключ чтения может быть извлечён; для сокрытия нужен сервер.

02.10.2026 проверены живые запросы с предоставленными пользователем данными: movie/popular — HTTP 200, 20 элементов; tv/popular — HTTP 200, 20 элементов; search/multi, запрос Интерстеллар — HTTP 200, 2 элемента.

Swift/Xcode отсутствуют: компиляция приложения и воспроизведение на iPhone не проверены. Atodo для видео остаётся отдельным источником и его доступность не восстановлена заменой каталога. Перед релизом добавьте утверждённый логотип и атрибуцию TMDB в About/Credits: https://developer.themoviedb.org/docs/faq.
