# Проверка каталога

Каталог использует https://api.atodo.fun/api/list. Проверка 01.10.2026 через сетевой шлюз среды разработки вернула HTTP 502 с сообщением Certificate verify failed: certificate has expired. Это указывает на проблему TLS сервера, но логи самого iPhone не получены.

Изменения: понятная ошибка TLS, корректная обработка отмены, независимое сохранение результатов фильмов и сериалов, повторная загрузка в диалоге ошибки и корректный Binding для его закрытия. Успешно загруженные ранее данные остаются при ошибке обновления. Проверка сертификатов не отключается.

Эти изменения не восстанавливают недоступный сервер Atodo. Для полного восстановления нужно обновление сертификата владельцем API или проверенный альтернативный источник.

Проверка: просмотр изменений и баланс скобок. Swift/Xcode отсутствуют в среде; компиляция и тесты на iPhone не выполнены. Перед использованием требуется сборка в Codemagic/macOS и проверка: оба запроса успешны; один неуспешен; TLS-ошибка; отмена запроса; закрытие ошибки и Повторить.
